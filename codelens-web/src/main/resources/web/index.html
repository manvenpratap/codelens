CodeLens Intelligence Platform — Feature & User Guide

Comprehensive walkthrough of workspace screens, 3D/2D visualizations, quality engines, and keyboard shortcuts

Workspace Navigation (6 Core Screens)

1. Graph View (1)

Call hierarchy and field impact canvas with force-directed physics, BFS depth pills (1–15 hops / Max), package convex hulls, quick inspector card, and radar minimap.

2. Knowledge Base (2)

Structured package/type/member catalog with Cyclomatic Complexity health scores (Green: 1–4, Amber: 5–10, Red: 11+ High Risk).

3. Codebase Visualizations (3)

Macro architectural exploration suite featuring 3D Software City, 3D Galaxy, 2D Graph, Treemap, Sunburst, DSM Matrix, and Chord diagram.

4. Code Review & Logic Auditor (4)

32 AST-backed static quality rules detecting null pointer risks, concurrency bugs, swallowed exceptions, smells, and high blast radius centrality.

5. Git Analytics & Churn (5)

Top author leaderboards, recent commit timeline, and hottest churned entities. Press H in Graph view to overlay thermal heat shaders.

6. Source Code Editor (6)

Embedded Microsoft Monaco code editor. Jump directly from any graph node or line link (`Class.java:42`) to edit and save files on disk.

Key Impact Investigation Workflows

Method Blast Radius Analysis: Search or click any method → Click ⬆ Callers in the Inspector → Expand BFS depth from 1 to 5 hops to trace all entrypoints and public controllers impacted by signature changes.
Field Mutation Propagation Chains: Select any field → Click 🔗 Propagation Chain in the Inspector → Traces Field ← Writer Methods ← Upstream Calling Triggers across the repository with color-coded node roles.
Repository Scan & Folder Exclusions: Click Browse… to pick your Java repository → Configure ⚙ Settings exclude patterns (`target, build, .mvn, .git, node_modules, **/test/**`) → Click Scan.

Interactive Architectural Renderers

🏙️ 3D Software City ("CodeCity")

Visualizes packages as elevated ground platforms and classes as skyscraper monoliths. Base footprint = method/field count, Height = lines of code (LOC), Roof color = complexity/churn. Orbit with mouse drag/wheel; adjust Exposure & Brightness slider.

🌌 3D Force Galaxy ("Orbital Graph")

Gravitational star cluster rendering code modules as orbital star systems with 3D quadratic bezier call arcs, animated particle pulses, and glowing celestial spheres.

🌸 2D Blooming Tree Graph

Whole-codebase force topology rendering classes and methods as connected nodes with fixed-position hover cards, tooltips, and click-to-detail inspector HUDs.

▦ Zoomable Treemap

Squarified area partitioner sizing rectangles by lines of code and coloring by complexity. Click any package or class rectangle to zoom in with breadcrumb navigation.

◉ Sunburst (Radial Hierarchy)

Concentric ring segments representing Package → Class → Method hierarchy. Segment angle reflects size; click ring slices to zoom radially.

⊞ Dependency Structure Matrix (DSM)

Sparse grid matrix displaying dependency counts between classes and packages. Highlights cyclic dependencies in red for architecture refactoring.

⌒ Chord Diagram

Circular arc visualizer with double-sided bezier ribbon polygons showing inter-package and inter-class call volume with directional linear gradients.

⚡ Granularity & POJO Filter

Toggle between Classes and Methods scope on the floating bottom toolbar. Enable Hide POJOs to filter out trivial getters and setters.

Graph Legend & Standard IDE Badges

m Method

Java member methods and constructors. Circle size reflects connectivity degree (callers + callees).

f Field / Property

Class fields and static variables. Tracks repository-wide reader and writer methods.

C Class

Standard Java classes. Contains member methods, fields, and inheritance relationships.

I Interface

Java interface contracts. Displays polymorphic implementation links across packages.

E Enum

Enumeration types with constant values and associated behavior.

R Record

Java 17+ immutable data carriers with auto-generated component accessors.

32 Static AST Quality Rules

1. Correctness Checks

Detects null pointer risks, unclosed resource streams (`AutoCloseable`), switch fallthrough bugs, and string comparison mistakes.

2. Concurrency Hazards

Flags non-thread-safe field mutations, unsynchronized static state access, double-checked locking anti-patterns, and thread pool leaks.

3. Exception Safety

Identifies swallowed exception blocks, raw `Throwable` catches, lost stack traces, and cleanup block failures.

4. Code Smells & Metrics

Flags long parameter lists ($>5$ params), high cyclomatic complexity ($>10$), dead code, and oversized classes ($>500$ LOC).

5. API Contracts & Docs

Audits missing Javadoc on public methods, broken `equals`/`hashCode` contracts, and mutable collection leaks.

6. Blast Radius Centrality

Identifies high-centrality methods that act as critical system bottlenecks and carry high refactoring risk.
