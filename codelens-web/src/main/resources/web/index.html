CodeLens Feature & Screen Guide

Graph Legend & Standard IDE Symbols

m Method

Java member methods and constructors. Circle size reflects connectivity degree (callers + callees).

f Field / Property

Class fields and static variables. Tracks repository-wide reader and writer methods.

C Class

Standard Java classes. Contains member methods, fields, and inheritance relationships.

I Interface

Java interface contracts. Displays polymorphic implementation links across packages.

E Enum

Enumeration types with constant values and associated behavior.

R Record

Java 17+ immutable data carriers with auto-generated component accessors.

Core Intelligence Capabilities

1. AST Source Indexing & Master Browse

Single-click folder selection parses 100% of Java AST structures and syncs Git history simultaneously into embedded H2 and Apache Lucene storage.

2. Knowledge Graph & Force Physics

Force-directed layout with Coulomb repulsion, Hooke spring tension, package convex hulls, and a toggleable Physics engine (Space) to freeze layouts.

3. Dynamic Call Hierarchy (BFS Depth)

Traverse upstream callers and downstream callees across selectable graph depths (1, 2, 3, 5, or Max hops) with zero lag.

4. Field Impact & Mutation Propagation

Traces every method reading or writing a field, plus full upstream caller chains (Field ← Writers ← Callers) across the entire codebase.

5. Git Intelligence & Churn Heatmap (H)

Renders live commit frequencies, churn levels, and top contributing authors directly onto graph nodes as thermal shaders.

6. Integrated Monaco Code Editor

Click any class, method, or link to inspect source files with full syntax highlighting and instant on-disk saving.

Screen & Panel Breakdown

Header: Single master Browse button to pick your Java repository, live AST entity counters (Types, Methods, Fields, Rels), and real-time scan progress bar.
Left Panel (Explorer & Search): Filter by Type chips, browse packages and member trees, or press ⌘K for instant Lucene search. Collapsible via [.
Centre Panel (5 Workspaces):
  • Graph (1): Interactive force canvas with depth pills, convex cluster hulls, live physics simulation, quick-inspector card, and minimap radar.
  • Knowledge Base (2): Structured catalog with member signatures, complexity metrics, and quick search.
  • Code Review (3): 32 AST-based static quality & concurrency checks with actionable fix recommendations.
  • Git (4): Commit author leaderboards, recent history, and hottest churned files.
  • Source (5): Embedded Monaco code editor for deep source inspection and live edits.
Right Panel (Inspector): Complete entity detail, Cyclomatic Complexity score bar, relationships, git blame telemetry, and editable analyst notes. Collapsible via ].

H Toggle Git commit churn heatmap on graph nodes

[ / ] Toggle Left Explorer / Right Inspector panels
