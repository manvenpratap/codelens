CodeLens Feature & Screen Guide

⚡ Five Core Analysis Capabilities

1. AST Source Indexing

JavaParser walks the source tree extracting classes, methods, fields, modifiers, lines, and relationships into an embedded database and Apache Lucene index.

2. Call Graph & Dynamic Depth

Calculates call hierarchies with configurable BFS depth (1 to 15 hops). Inspect immediate callers, downstream dependencies, or full transitives.

3. Field Impact & Propagation

Traces every method reading or writing a field, plus full upstream caller chains (Field ← Writers ← Callers) across the entire repo.

4. Structural Inconsistency Detection

Identifies signature divergence across same-named methods, naming drift, and duplicate logic blocks via AST hash comparisons.

5. Git Intelligence & Heatmaps

Extracts per-entity commit frequencies, churn levels, top author contributions, and renders hot entities directly onto graph nodes.

6. In-App Monaco Editor

Jump directly to exact source lines, inspect Java source files with syntax highlighting, and perform local edits safely.

🖥️ Screen & Panel Breakdown

Header: Input absolute source paths, run scans, inspect live type/method/field counters, and check progress.
Left Panel (Explorer & Search): Filter by Class/Iface/Enum chips, browse packages, or press ⌘K for Lucene search.
Centre Panel (5 Workspaces):
  • Graph: Force-directed interactive canvas with depth slider, fit view, and fire heat overlay.
  • Knowledge Base: Structured catalog with complexity metrics and signatures.
  • Inconsistencies: Prioritized list of code drift and clone warnings.
  • Git: Author ranking and entity churn metrics.
  • Source: Full Monaco code editor view.
Right Panel (Inspector): Complete entity breakdown, Cyclomatic Complexity score bar, relationships, git metadata, and editable analyst notes.
